# Lookbook Index

A running index of 315 clothing labels and their newest lookbooks.

- **Just in** (front page): the latest lookbooks, collections and collabs, laid out by release date.
- **Index**: every label A–Z or by date, filterable by category, origin and price.

Data:
- `brands.json`: the label directory.
- `drops.json`: the feed, refreshed weekly. A drop can show a real cover by putting an image in `covers/` and adding `"cover": "covers/<file>"` to its entry.

Live at https://jere-mee-as.github.io/lookbookindex/ · Made by Jere.
